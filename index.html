Featured Artifact

Travlr Getaways Full-Stack Application

The primary artifact featured in this ePortfolio is the Travlr Getaways application originally created during CS-465 Full Stack Development.

The application is a full-stack travel application developed using:

  • Node.js
  • Express.js
  • Angular
  • MongoDB
  • Mongoose

The application allows users to view travel destinations while authenticated administrators can manage trip information through database-driven operations.

During CS-499, I used this project as the foundation for three separate enhancements covering software engineering, algorithms and data structures, and databases.
