Featured Artifact: Travlr Getaways

The Travlr Getaways application is a full-stack travel management application originally created for CS-465. It uses Angular for the frontend, Node.js and Express for backend services, and MongoDB with Mongoose for database functionality.

The original application allowed users to view travel destinations while authenticated administrators could manage trip information. During CS-499, I used this application as the foundation for three planned enhancements.

Technologies Used

  • Angular
  • Node.js
  • Express.js
  • MongoDB
  • Mongoose
  • JavaScript
  • REST APIs
