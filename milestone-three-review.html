Milestone Three: Enhancement Two — Algorithms & Data Structures

Noah Johnson | CS-499 | July 20, 2026

Artifact Description

The artifact I selected for my ePortfolio is the Travlr Getaways full-stack web application that I developed during my CS-465 Full Stack Development course.

This application was created to provide users with a travel management system where they can view available trips and interact with trip information through a web-based interface.

The application uses Node.js, Express, MongoDB, Mongoose, and Angular to create a complete full-stack solution.

Original Functionality

The original artifact included functionality for retrieving, creating, updating, and deleting trip information.

The backend API provided routes for accessing trip data from the MongoDB database and allowed authenticated users to manage trip records.

While the application successfully implemented basic CRUD operations, the original version had limited functionality for users who needed to locate specific trips from a larger collection of available travel options.

Algorithm Enhancement

For my CS-499 enhancement, I focused on improving the application's algorithms and data retrieval capabilities by implementing a search functionality within the backend API.

This enhancement allows users to search for trips based on relevant information such as trip name, resort, and description.

The new search functionality provides users with a more efficient way to locate relevant travel information without manually reviewing every available trip.

Search Implementation

The enhancement introduced a new search function in the trip controller. The function accepts a search term from the user and uses MongoDB query operations to identify matching records.

The search examines multiple fields, including the trip name, resort, and description. Regular expressions with case-insensitive matching were used to make the search more flexible for users.

A new API endpoint was also added to connect user requests with the search functionality:

GET /trips/search?query=value

This route allows the application to receive a search term and return filtered trip results from the database.

Files Enhanced

The primary files modified for this enhancement were:

  • app_api/controllers/trips.js
  • app_api/routes/index.js

The controller contains the search logic, while the routes file connects the new endpoint to the controller function.

The enhancement also demonstrates my ability to use appropriate computing techniques and tools to develop a solution that improves application functionality and user experience.
