Artifact Description

The artifact I selected for my ePortfolio is the Travlr Getaways full-stack web application that I developed during my CS-465 Full Stack Development course.

This application was created to provide users with a travel management system where they can view available trips and interact with trip information through a web-based interface. The application uses a combination of technologies including Node.js, Express, MongoDB, Mongoose, and Angular to create a complete full-stack solution.

The original artifact included functionality for retrieving, creating, updating, and deleting trip information. The backend API provided routes for accessing trip data from the MongoDB database and allowed authenticated users to manage trip records.

While the application successfully implemented basic CRUD operations, the original version had limited functionality for users who needed to locate specific trips from a larger collection of available travel options.

Algorithm and Data Structure Enhancement

For my CS-499 enhancement, I focused on improving the application's algorithms and data structures capabilities by implementing a search functionality within the backend API.

This enhancement allows users to search for trips based on relevant information such as trip name, resort, and description. Instead of requiring users to manually review every available trip, the search functionality allows the application to filter the available results based on the user's search term.

Search Implementation

The search functionality was implemented within the backend API. A new search controller processes the user's search term and queries MongoDB for matching trip information.

The search functionality uses MongoDB query operations and regular expressions to search across multiple fields. The search is case-insensitive, allowing users to find results without needing to match the exact capitalization of stored information.

A new API endpoint was also added to allow the application to request search results: 

GET /trips/search?query=value

This route connects the user's search request to the backend search functionality and returns the trips that match the provided search criteria.

Learning and Reflection

Implementing this enhancement helped me better understand how algorithms can be applied to practical software problems. The goal was not simply to add another feature, but to create a more useful method of retrieving information from the application's database.

I learned that algorithmic improvements can directly affect the user experience. A well-designed search process reduces the amount of information a user needs to manually review and provides a more efficient way to locate relevant information.

One challenge was determining which fields should be included in the search. I selected the trip name, resort, and description because these fields contain information that users are most likely to use when searching for a destination.

Another challenge was ensuring that the search functionality worked correctly with different capitalization and partial search terms. Using case-insensitive regular expression matching helped make the functionality more flexible.

Course Outcomes

This enhancement supports the Computer Science program outcome related to designing and evaluating computing solutions using algorithmic principles and computer science practices.

It also demonstrates the ability to use computing techniques and tools to implement a solution that provides value to users. The search functionality improves the application's usability while working within the existing architecture of the Travlr Getaways application.

Overall, this enhancement allowed me to apply algorithmic problem solving to an existing application while maintaining its original functionality and structure.
