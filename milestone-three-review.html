Artifact Description

The artifact I selected for my ePortfolio is the Travlr Getaways full-stack web application that I developed during CS-465 Full Stack Development.

The application provides users with a travel management system where they can view available trips and interact with trip information through a web-based interface.

The application uses Node.js, Express, MongoDB, Mongoose, and Angular to create a complete full-stack solution.

Original Functionality

The original artifact included functionality for retrieving, creating, updating, and deleting trip information.

The backend API provided routes for accessing trip data from the MongoDB database and allowed authenticated users to manage trip records.

While the application successfully implemented basic CRUD operations, the original version had limited functionality for users who needed to locate specific trips from a larger collection.

Algorithm Enhancement

For my CS-499 enhancement, I focused on improving the application's algorithms and data retrieval capabilities by implementing a search functionality within the backend API.

This enhancement allows users to search for trips based on relevant information such as trip name, resort, and description.

Search Controller

I added a new tripsSearch() function to the trip controller. The function accepts a search term from the user and uses MongoDB query operations to locate matching trip records.

The search checks multiple fields, including the trip name, resort, and description. Case-insensitive regular expressions are used so that users do not have to enter search terms with exact capitalization.

API Endpoint

I also added a new API endpoint:

GET /trips/search?query=value

This route connects user requests to the new search functionality and allows the application to return filtered trip results.

Why the Enhancement Matters

Before this enhancement, the application primarily relied on retrieving all trips or searching for a specific trip using its trip code. This limited the ability of users to efficiently find trips based on broader criteria.

The new search functionality improves the user experience by allowing users to locate relevant trips without manually reviewing every available record.

This enhancement also demonstrates how algorithmic problem solving can be applied directly to a real-world application. The search process takes user input, evaluates multiple database fields, and returns records that match the requested criteria.

Reflection

This enhancement helped me better understand how algorithms and data retrieval techniques can directly improve the functionality of an application.

Rather than adding a completely separate feature unrelated to the existing application, I identified a limitation in the original system and developed a solution that worked within the application's existing architecture.

This experience strengthened my ability to analyze an existing application, identify opportunities for improvement, and implement an efficient solution while preserving existing functionality.
