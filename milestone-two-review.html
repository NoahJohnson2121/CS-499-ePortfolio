Artifact Description

The artifact selected for my ePortfolio is the Travlr Getaways comprehensive web application I developed in CS-465 Full Stack Development.

The application uses Angular for the client-side interface, Node.js and Express for server-side operations, and MongoDB with Mongoose for data management.

Users can explore travel locations, while authenticated administrators have the capability to create, modify, and remove trip details through the administrative portion of the application.

Reason for Selection

I selected this artifact because it effectively demonstrates my skills in software design and engineering by integrating multiple technologies within a single application.

The project demonstrates frontend development through Angular, backend API development using Express, RESTful web services, authentication, MongoDB integration, and the organization of a larger application into reusable components, services, routes, controllers, and data models.

Software Engineering Enhancements

For this enhancement, I focused on refining the software engineering elements of the application rather than changing its fundamental purpose.

I reorganized portions of the application's architecture to improve clarity and maintainability. I also strengthened input validation, expanded error handling, improved authentication reliability, and added more comprehensive documentation throughout the project.

These changes make the application easier to maintain and understand while also improving its reliability when unexpected or invalid information is encountered.

Computer Science Outcomes

The improvements made for this milestone align with several outcomes within the Computer Science curriculum.

First, the project demonstrates my ability to design and evaluate computing solutions using software engineering principles and industry practices.

The enhancements also demonstrate my ability to create higher-quality software by improving maintainability, documentation, organization, and reusable components.

Finally, the modifications promote a security-focused approach by strengthening input validation and error handling to reduce the potential for invalid or harmful information to enter the system.

Progress Toward Course Outcomes

These improvements closely align with the objectives established in my Module One enhancement strategy. The software engineering enhancement established the foundation for the algorithm and database improvements completed in the following milestones.

Reflection

Improving this artifact gave me the opportunity to revisit a project I had previously completed and evaluate it through the perspective of a software engineer rather than simply completing coursework.

I learned that functional software is only one part of professional development. Readability, maintainability, organization, security, documentation, and reliability are equally important when developing software that other people may need to maintain.

A significant challenge was identifying improvements that provided real value without changing the fundamental purpose of the application. Instead of simply adding unnecessary features, I focused on improving the quality and reliability of the existing codebase.

This experience strengthened my understanding of how professional developers continuously refine existing software instead of always building applications from the beginning.
