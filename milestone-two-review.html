Milestone Two: Enhancement One — Software Engineering

Noah Johnson | CS-499 | July 13, 2026

Artifact Description

The piece chosen for my ePortfolio is the Travlr Getaways comprehensive web application I developed in CS-465, Full Stack Development.

This project utilized Angular for the client-side interface, Node.js and Express for server-side operations, and MongoDB with Mongoose for data management. Users can explore travel locations, while verified administrators have the capability to create, modify, and remove trip details through a secure administrative platform.

Reason for Selection

I opted for this artifact because it effectively showcases my skills in software design and engineering by integrating numerous technologies within a single application.

This project highlights my proficiency in frontend development through Angular, backend API creation using Express, RESTful web services, user authentication, and the incorporation of a MongoDB database.

It also illustrates my competency in structuring a larger project into reusable modules, services, routes, controllers, and data models.

Software Engineering Enhancements

For this enhancement, I concentrated on refining the software engineering elements of the application instead of introducing entirely new features.

I reorganized portions of the application's architecture to improve clarity and maintainability. I also strengthened input validation, expanded error handling, improved authentication reliability, and included more comprehensive documentation throughout the project.

These revisions contribute to greater maintainability, simplify understanding for fellow developers, and improve reliability when the application encounters unexpected conditions.

Course Outcomes

The improvements made for this milestone align with several outcomes within the Computer Science curriculum.

The project demonstrates my ability to design and assess computing solutions using software engineering principles and industry practices.

The enhancements also demonstrate my ability to create higher-quality software by improving maintainability, documentation, validation, and organization.

Finally, these modifications promote a security-focused approach by improving input validation and error handling to reduce the possibility of invalid or harmful data entering the application.

Progress Toward Course Outcomes

These modifications closely align with the objectives outlined in my Module One enhancement strategy. The software engineering enhancement established a foundation for the additional improvements completed during the following milestones.

The remaining enhancements focused on strengthening the application's algorithms and database implementation.

Reflection

Improving this artifact provided me with the opportunity to revisit a project I had previously completed during my studies and evaluate it through the perspective of a software engineer rather than simply fulfilling coursework requirements.

During the evaluation, I recognized that creating functional software is only one aspect of professional software development. Readability, maintainability, organization, security, and documentation are equally important.

A significant challenge was identifying enhancements that provided meaningful value without changing the fundamental purpose of the application.

Rather than simply adding new features, I focused on improving the quality of the existing codebase through better organization, validation, and maintainability.

This experience helped me understand how professional developers continuously refine existing software instead of always creating applications from the ground up.

Overall, the enhancement strengthened my technical abilities and deepened my understanding of professional software engineering practices.
