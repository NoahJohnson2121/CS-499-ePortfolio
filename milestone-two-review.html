Artifact Description

The piece chosen for my ePortfolio is the Travlr Getaways comprehensive web application I developed in CS-465, Full Stack Development. This project utilized Angular for the client-side interface, Node.js and Express for server-side operations, and MongoDB with Mongoose for data management. Users can explore travel locations, while verified administrators have the capability to create, modify, and remove trip details through a secure administrative platform.

Reason for Selection

I opted for this artifact as it effectively showcases my skills in software design and engineering, integrating numerous technologies within a singular application. This project highlights my proficiency in frontend development through Angular, backend API creation using Express, RESTful web services, user authentication, and the incorporation of a MongoDB database.

It also illustrates my competency in structuring a large-scale project into reusable modules, services, routes, controllers, and data models.

Enhancements

For this enhancement, I concentrated on refining the software engineering elements of the application instead of introducing entirely new features. I reorganized the application's architecture by restructuring certain code segments to enhance clarity and maintainability.

Additionally, I strengthened input validation processes, expanded error handling measures, improved authentication reliability, and included more comprehensive documentation throughout the project.

These revisions contribute to greater maintainability, simplify understanding for fellow developers, and bolster reliability in unforeseen circumstances.

Course Outcomes

The improvements made for this milestone align with several outcomes within the Computer Science curriculum. Firstly, the project illustrates my capacity to design and assess computing solutions guided by software engineering principles and leading industry practices.

Secondly, the enhancements reflect my ability to create high-quality software by boosting maintainability, elevating documentation quality, and organizing code into reusable parts.

Lastly, these modifications promote a security-focused approach by refining input validation and error handling to minimize the risk of invalid or harmful data entering the application.

Outcome Coverage

These modifications closely align with the objectives outlined in my Module One enhancement strategy. Currently, I do not expect to make major changes to my overall coverage of outcomes. Upcoming milestones will emphasize strengthening the application's algorithms and database framework.

Reflection

Improving this artifact provided me the opportunity to revisit a project I had previously completed during my studies and assess it through the lens of a software engineer rather than merely fulfilling coursework obligations.

Throughout the evaluation, I recognized that delivering functional software is merely one aspect of professional software development. Factors such as readability, maintainability, organization, security, and documentation carry equal significance.

A significant obstacle faced was pinpointing enhancements that provided real value while not altering the fundamental intent of the application. Rather than merely incorporating new features, my emphasis was on refining the quality of the current codebase by enhancing organization, bolstering validation, and increasing maintainability.

This experience offered insights into how seasoned developers consistently refine existing software instead of perpetually building new applications from the ground up.

In summary, the enhancements not only bolstered my technical abilities but also deepened my grasp of optimal software engineering practices, laying a solid groundwork for the additional improvements completed during the CS-499 capstone project.
