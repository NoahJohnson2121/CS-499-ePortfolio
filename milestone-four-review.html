Milestone Four: Enhancement Three — Databases

Noah Johnson | CS-499 | July 29, 2026

Artifact Description

The artifact selected for my database enhancement is the Travlr Getaways full-stack web application that I originally developed during CS-465 Full Stack Development.

This application was created as part of my Computer Science coursework and uses a MEAN stack architecture consisting of MongoDB, Express.js, Angular, and Node.js. The application allows users to view travel destinations while providing administrative functionality for managing trip information through database-driven operations.

The database component of this application uses MongoDB with Mongoose to define and manage trip data. The original artifact contained a functional database structure with schema definitions and CRUD operations, but there were opportunities to improve data integrity and validation.

Reason for Selection

I selected the Travlr Getaways application for my ePortfolio because it demonstrates multiple areas of computer science, including software engineering, algorithms, and database development.

The artifact represents my ability to build a complete full-stack application and improve an existing solution through analysis and refinement.

Database Enhancements

For the database enhancement, I focused on improving the reliability and consistency of the MongoDB data layer.

The original database implementation stored trip information successfully but did not enforce uniqueness for trip identifiers or provide all of the validation needed to ensure consistent data.

To improve this, I enhanced the Mongoose schema by adding a unique constraint to the trip code field. This prevents duplicate trip records from being created with the same identifier and improves overall data integrity.

I also strengthened validation within the Mongoose schema by adding required fields, length restrictions, trimming, and other validation rules where appropriate. These changes help prevent incomplete or improperly formatted information from being stored in the database.

Database Validation

The enhanced schema provides stronger rules for important trip properties such as the trip code, trip name, resort, price, image, and description.

These validation rules improve the consistency of the data stored in MongoDB and make the database more reliable for the rest of the application.
