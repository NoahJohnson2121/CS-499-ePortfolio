# Enhancement 2 - Algorithms and Data Structures

## Overview

The second CS-499 enhancement focused on algorithms and data structures.

The primary improvement was the addition of search functionality to the Travlr Getaways application. This enhancement allows users to search for trips using information such as the trip name, resort, and description.

### Code Review

The code review explains the original functionality and identifies the opportunity to improve how users locate travel information.

[View Enhancement 2 Code Review](./4-2%20Milestone%20Three%20Enhancement%20Review)

### Enhancement

The search enhancement added functionality that allows users to provide a search term and receive matching trip results.

The enhancement included changes to the trip controller and API routes.

A search endpoint was added using:

`GET /trips/search?query=value`

The search functionality uses MongoDB query operations and case-insensitive regular expressions to locate matching information across multiple trip fields.

### Enhanced Artifact

[View/Download Enhancement 2 Project](./4-2%20Milestone%20Three%20Enhancement%20Two.zip)

### Supporting Evidence

# Enhancement 3 - Databases

## Overview

The third CS-499 enhancement focused on improving the database implementation used by the Travlr Getaways application.

The project uses MongoDB with Mongoose to store and manage travel information.

### Code Review

The database review identified opportunities to improve data integrity, validation, and the reliability of information stored in MongoDB.

[View Enhancement 3 Code Review](./5-2%20Milestone%20Four%20Enhancement%20Review)

### Enhancements

The database enhancement focused on targeted improvements rather than completely redesigning the database.

The improvements included:

- Strengthened Mongoose schema validation
- Added required fields
- Added field length restrictions
- Improved string handling
- Improved data integrity
- Added database indexing where appropriate
- Improved maintainability of the database model

# Professional Growth

CS-499 provided an opportunity to revisit projects that I had previously completed and evaluate them from a more professional perspective.

One of the most important lessons from the capstone was learning that completing a functional application is only one part of software development. Professional software must also be maintainable, secure, understandable, and designed with future users and developers in mind.

The enhancement process required me to analyze existing code, identify weaknesses, determine appropriate improvements, implement those improvements, and evaluate the results.

This process helped me transition from simply asking whether my code works to asking whether a solution is reliable, secure, maintainable, and appropriate for its intended purpose.
